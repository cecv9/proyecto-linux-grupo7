# Índice de evidencias por fase

Las capturas del proyecto están organizadas por fase. Cada carpeta contiene las imágenes,
los archivos de texto de apoyo y un `README.md` con el objetivo, los comandos principales y
la descripción breve de cada evidencia.

| Fase | Carpeta | Contenido |
|---|---|---|
| 00 | [fase-00-preparacion](fase-00-preparacion/README.md) | Preparación del entorno (11 evidencias) |
| 01 | [fase-01-administracion-basica](fase-01-administracion-basica/README.md) | Administración básica, usuarios y permisos (5 evidencias) |
| 02 | [fase-02-automatizacion-monitoreo](fase-02-automatizacion-monitoreo/README.md) | Automatización y monitoreo (5 evidencias) |
| 03 | [fase-03-control-versiones](fase-03-control-versiones/README.md) | Control de versiones y GitHub (35 evidencias) |
| 04 | [fase-04-docker](fase-04-docker/README.md) | Instalación y configuración de Docker (46 evidencias) |
| 05 | [fase-05-nginx-basico](fase-05-nginx-basico/README.md) | Servidor web Nginx básico (10 evidencias) |
| 06 | [fase-06-imagen-personalizada](fase-06-imagen-personalizada/README.md) | Imagen personalizada con Dockerfile (12 evidencias) |

## Cómo leer una evidencia

1. Abre la carpeta de la fase.
2. Lee su `README.md` para entender el objetivo y los comandos.
3. Abre la imagen o el `.txt` que corresponde al paso que quieres comprobar.

> Las descripciones son breves. El informe PDF desarrolla cada comando con más detalle.
