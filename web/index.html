Servidor Linux automatizado con Docker

Grupo 7 · Ciclo II–2026

¿Qué estás viendo?

Este sitio se sirve desde un contenedor Nginx dentro de una máquina virtual Debian 13. El contenido se monta desde /proyecto/web y se publica en el puerto 8080 del host.

Servicios del proyecto

  • 8080: Nginx oficial con bind mount del sitio.
  • 8081: imagen personalizada servidor-grupo7.
  • 8082: Nginx en la red red-proyecto.
  • 8083: Nginx con el volumen volumen-web.

Automatización

El script reporte_sistema.sh se ejecuta cada 30 minutos mediante cron y registra el estado del servidor en /var/log/proyecto/reporte_sistema.log.
